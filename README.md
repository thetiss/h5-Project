# H5 前端项目

一个规范的 H5 前端项目模板。

## 项目结构

```
h5-project/
├── index.html          # 主页面入口
├── README.md           # 项目说明文档
├── variable.scss       # CSS 变量定义（全局样式变量）
├── css/                # 样式文件目录
│   ├── style.css       # 主样式表
│   └── FullPageScroll.scss  # 全页滚动样式
├── js/                 # 脚本文件目录
│   └── main.js         # 主入口脚本
├── images/             # 图片资源目录
│   └── (存放 .png, .jpg, .svg 等图片文件)
└── fonts/              # 字体文件目录
    └── (存放 .woff, .woff2, .ttf 等字体文件)
```

## 目录说明

| 目录 | 说明 |
|------|------|
| `css/` | 存放 CSS 样式文件 |
| `js/` | 存放 JavaScript 脚本文件 |
| `images/` | 存放项目所需的图片资源 |
| `fonts/` | 存放自定义字体文件 |

## 快速开始

直接用浏览器打开 `index.html` 即可预览项目。

## 浏览器支持

- Chrome (推荐)
- Firefox
- Safari
- Edge
- IE11+
